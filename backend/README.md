# Food Ordering & Delivery App

A full-stack food ordering and delivery application built with Spring Boot and React.

## Tech Stack
- Java 21
- Spring Boot
- Spring Security + JWT
- MySQL / PostgreSQL
- React
- Stripe Payment
- AWS (EC2, S3, RDS)

## Features
- User authentication and authorization
- Food ordering and checkout
- Payment integration with Stripe
- Order management
- Cloud-ready deployment

## How to Run
1. Configure `application.properties`
2. Run the Spring Boot application
3. Start the React frontend
